# DEMO — how to show (not just tell) this repo

GitHub READMEs cannot play video inline (GitHub strips `<video>`/iframes, still true in 2026).
Use this ladder:

## 1. README (works today)
- **Animated GIF** (`docs/img/demo.gif`, <5–8MB): regenerate reproducibly with
  `vhs docs/demo.tape` (VHS: `brew install vhs`, or Docker `ghcr.io/charmbracelet/vhs`).
  The `.tape` file is committed, so the GIF regenerates exactly when outputs change.
- **Clickable video thumbnail** → YouTube: record once (terminal or `preview.html` tour),
  upload to YouTube, embed:
  `[![Watch the demo](docs/img/demo-thumb.png)](https://www.youtube.com/watch?v=YOUR_VIDEO_ID)`
- **Screenshots with real numbers**: `docs/img/equity_real.png`, `sharpe_real.png`,
  `wfc_real.png` — generated by `scripts/make_charts.py` from live data, never hand-drawn.

## 2. GitHub Pages (full video + interactive quiz)
- `preview.html` is a self-contained page (HTML+CSS+JS, no build). Enable:
  repo **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**,
  then open `https://<user>.github.io/<repo>/preview.html`.
- Pages allows `<video>` embeds: put `docs/demo.mp4` next to `preview.html` and it plays inline.
- The quiz in `preview.html` runs 100% client-side — no server needed.

## 3. Recording checklist (30–60s, one take)
1. `bash scripts/run_all.sh` (fetch + baselines + loop).
2. `cat results/self_improving_summary.csv` (the money line: SPY promoted, crypto held).
3. Open `preview.html`, answer 3 quiz questions.
Keep it under 60s; re-record on release (stale demos erode trust faster than no demo).
